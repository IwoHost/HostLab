01LINUX BASH — KOMENDY
pwd
Pokaż bieżący katalog
$ pwd → /home/student
ls [-la]
Listuj pliki. -l szczegóły, -a ukryte
$ ls -la
cd [ścieżka]
Zmień katalog. cd .. wyżej. cd ~ domowy
$ cd dokumenty
mkdir [nazwa]
Utwórz katalog. -p tworzy całą ścieżkę
$ mkdir -p a/b/c
touch [plik]
Utwórz pusty plik
$ touch plik.txt
cat [plik]
Wyświetl zawartość pliku
$ cat notatki.txt
echo [tekst]
Wypisz tekst. > nadpisz, >> dopisz
$ echo "cześć" > plik.txt
cp [src] [dst]
Kopiuj plik. -r kopiuje katalogi
$ cp plik.txt kopia.txt
mv [src] [dst]
Przenieś lub zmień nazwę
$ mv stara.txt nowa.txt
rm [plik]
Usuń plik. -r katalogi. Brak kosza!
$ rm -r folder/
grep [wzorzec]
Szukaj tekstu. -i bez wielkości liter
$ grep -i "root" /etc/passwd
chmod [tryb]
Zmień uprawnienia. +x dodaj wykonanie
$ chmod 755 skrypt.sh
| (pipe)
Wyjście jednej komendy → wejście drugiej
$ ls | grep .txt
> i >>
> nadpisuje plik. >> dopisuje na koniec
$ echo "abc" >> plik.txt
02CHMOD — UPRAWNIENIA PLIKU
r=4 (read)   w=2 (write)   x=1 (execute)  | suma cyfr = tryb dla owner/group/others
TRYBCYFRYOPIS
rwxrwxrwx777Każdy może wszystko
rwxr-xr-x755Właściciel pełny, reszta r+x
rw-r--r--644Właściciel r+w, reszta tylko r
rw-------600Tylko właściciel r+w
rwx------700Tylko właściciel pełny dostęp
r-xr-xr-x555Wszyscy r+x, nikt nie pisze
Składnia symboliczna: chmod u+x (user+execute), chmod go-w (group i others − write), chmod a=r (wszyscy = read)
SYMBOLZNACZENIE
uuser — właściciel pliku
ggroup — grupa właściciela
oothers — wszyscy inni
aall — wszyscy (= ugo)
+dodaj uprawnienie
-usuń uprawnienie
=ustaw dokładnie (nadpisz)
03WINDOWS CMD — KOMENDY
dir [/b /ad]
Lista plików. /B tylko nazwy, /AD katalogi
> dir /b
cd [ścieżka]
Zmień katalog. cd .. wyżej, cd \ główny
> cd C:\Users
md / mkdir
Utwórz katalog
> md nowy_folder
rd [/s]
Usuń katalog. /S z zawartością
> rd /s stary
del [plik]
Usuń plik. Bez kosza!
> del plik.txt
copy [src] [dst]
Kopiuj plik
> copy a.txt b.txt
move [src] [dst]
Przenieś lub zmień nazwę
> move stara.txt nowa.txt
type [plik]
Wyświetl zawartość (jak cat)
> type notatki.txt
echo [tekst]
Wypisz tekst. echo. = pusta linia
> echo Cześć!
@echo off
Wyłącz echo komend. Zawsze na początku .bat
@echo off
set [VAR=val]
Zmienna. Odczyt: %VAR%
> set X=5 & echo %X%
if exist
Sprawdź czy plik istnieje
> if exist a.txt echo OK
for %i in (...)
Pętla. W .bat: %%i (podwójny %)
> for %i in (1 2 3) do echo %i
rem [tekst]
Komentarz — linia ignorowana
rem To jest komentarz
cls / pause
cls czyści ekran. pause czeka na klawisz
> cls
04STRUKTURA PLIKU .BAT
WAŻNE: W pliku .bat używamy %%i w pętlach for (nie %i jak w CMD). Każda linia to jedna komenda.
Typowy plik .bat
@echo off
rem Opis co robi skrypt

set ZMIENNA=wartość
echo Witaj, %USERNAME%!

if exist plik.txt (
echo Plik istnieje
) else (
echo Brak pliku
)

for %%i in (*.txt) do (
echo Plik: %%i
)

pause
